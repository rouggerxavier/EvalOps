## Regras para novos docs

- Separar auditoria, plano de implementacao e definicao de pronto.
- Citar arquivos/rotas reais quando a afirmacao depender do codigo.
- Marcar explicitamente o que esta implementado, parcial ou faltando.
- Nao manter docs historicos que contradigam o estado atual do produto.
