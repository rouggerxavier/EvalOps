# /caveman-compress

Compress a natural-language markdown memory file into caveman format.

## Arguments

- `filepath`: markdown or text file to compress.

## Workflow

1. Use the `caveman-compress` skill.
2. Preserve code blocks, commands, paths, URLs, frontmatter, tables, and structured data.
3. Create the human-readable backup described by the skill before overwriting.
4. Run the skill validation script after compression.
